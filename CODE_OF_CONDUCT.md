# Contributor Covenant Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
code of conduct, version 2.1. By participating, you agree to uphold this standard.

For the full text, see https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Report unacceptable behavior to elijahr@gmail.com. All complaints will be
reviewed and investigated promptly and fairly. All reports will be handled with
discretion, and the privacy and security of the reporter will be respected.
