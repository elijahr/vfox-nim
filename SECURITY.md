# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in vfox-nim, please report it
responsibly. **Do not open a public issue.**

The preferred channel is GitHub's private vulnerability reporting: go to the
[Security tab](https://github.com/elijahr/vfox-nim/security) of this repository
and click **"Report a vulnerability"**. This keeps the report private until a fix
is available.

If you cannot use private reporting, email **elijahr@gmail.com** instead.

Please include:

- A description of the vulnerability
- Steps to reproduce
- Impact assessment (if known)

We will acknowledge receipt within 48 hours and aim to provide an initial
assessment within 5 business days.

## Supported Versions

| Version | Supported   |
| ------- | ----------- |
| 0.1.x   | Yes         |
| < 0.1   | Best effort |
